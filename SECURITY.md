# Security and privacy

ZeroedIn Performance Lab V1 is a local-first showcase. It binds to `127.0.0.1`, stores records in a local SQLite database, and does not provide public accounts or cloud synchronization.

Do not expose this version directly to the public internet or use it to collect public data. Do not enter classified information, controlled information, mission details, deployment locations, government identifiers, or information about other personnel without authorization.

If you discover a security issue, report it privately to the repository owner rather than opening a public issue containing sensitive details.
